# 微信小程序提交审核说明

小程序名称建议：纪念日时间计算器

## 建议类目

- 首选：工具 → 信息查询
- 备选：生活服务 → 生活工具

本小程序提供纪念日记录、日期差计算、公历农历日期换算，属于工具查询，不含社交、支付、UGC 社区。

## 提交审核用功能说明（可直接粘贴）

本小程序用于记录个人纪念日并计算距今天数，同时提供两个日期相差天数、公历与农历日期换算。

主要功能：

1. 纪念日：用户可新增事件名称、公历或农历日期、是否每年重复、备注；首页按距下次纪念日天数排序，高亮今天的纪念，支持左滑编辑和删除。
2. 额度：默认最多保存 3 条。完整观看一次激励视频可增加 1 条可保存额度，最多 20 条。每条纪念日自保存起有效 30 天，用户可对该条单独观看视频，在其到期日上再延续 30 天。已有记录不会因额度变化被删除。
3. 日期工具：计算两个日期相差天数；公历与农历互相换算，仅输出对应日期。
4. 我的：查看当前额度、阅读隐私说明、一键清除本机数据。

数据默认仅保存在用户手机本地，不强制登录，不收集手机号、微信昵称或头像。农历功能仅为日期换算，不提供黄历、宜忌、吉凶、运势或任何测算内容。广告由微信流量主提供，用于扩展可保存条数和页面信息展示，基础记录与换算功能不强制观看广告。

## 隐私与用户信息

- 不要求登录
- 不收集身份证、手机号、位置、通讯录
- 默认不读取 openid（仅当运营者自行开启云同步后，才用云函数 login 获取 openid 做数据隔离）
- 用户可在「我的 - 清除本机数据」删除全部记录
- 隐私说明页路径：`pages/privacy/privacy`

配置小程序隐私协议时，可写：本小程序不收集个人信息，纪念日数据仅保存在用户本机。

## 广告说明（填在审核补充里）

- 激励视频：用户主动点击后播放。完整观看可增加 1 条本地额度，或为指定的一条纪念日延续 30 天有效期
- Banner：纪念日、工具、我的页面底部
- 未开通流量主前请保持广告 ID 为空，不要提交无法播放的假广告位
- 不上线「看广告领现金/积分」、强制分享、诱导点击

流量主需小程序先过审上线后再申请。首次提交可以只有占位，功能需完整可演示。
